## 当前证据

在上述 62 条标签中，同角色共有 117 对：67 对已同组，50 对仍分开；不同角色错合为 0 对。50 对漏合集中在 `teo`（39）、`trainer`（6）、`皇帝`（5）。这是片段配对数，不是丢失的音频条数；计算口径见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md#评估怎么读)。未标注片段是否混人仍未知。

已经完成的对照没有解决瓶颈：

- 两模型共 142 个阈值设置：没有直接用 WeSpeaker 替换 ReDimNet 的证据。
- 少量身份参考共 200 次设置：连接参考所在组的收益有限；直接按最近参考归属容易拆散原组或新增混人。
- 这些结果来自已有标签的探索，不能称为新集盲测，也不能证明所有嵌入或参考方法都无效。

## 当前想法：嵌入可能是主要瓶颈，尚未定论

理想的嵌入应让同角色在不同说话方式下仍接近，让不同角色保持可区分。现有方法出现“收紧则碎、放宽则混”，因此有理由优先检查表示与距离是否提供了足够的身份线索。

但需要区分：身份信息本身不足、余弦距离或分组规则没有利用好信息、输入过短或异常导致表示不稳定。目前没有系统测量近邻身份检索与同人/异人距离重叠，也未确认情绪、场景或切段是哪一个因素在主导错误。不能把这些猜想写成已测根因。

## 下一步：先诊断嵌入，不先重切或继续调聚类

**尚未实施。** 固定现有片段、人工标签和两模型缓存，不重跑音频模型，不改变当前导出。

1. **同角色能否互相找到。** 在精确匹配的人工身份片段中，排除查询自身，报告 Top-1 的同角色命中率和 Top-3/5 中至少找到一个同角色的比例，同时报按角色平均及各角色结果。只有一条标签的角色不作为此项查询，但继续作为干扰候选。明确有效查询数；同集与跨集分别报告可评价覆盖，跨集只有存在同角色候选时才能计命中。
2. **区分程度与具体错误。** 对照同人/异人的余弦距离分布、最近同人和最近异人的相对距离，定位“同人很远”“异人很近”及组内/组间失败。按片段时长分层，避免仅凭总体分数断言原因。两模型必须用同一候选池，不能把未标注片段当错误身份。
3. **少量错误实例复核。** 按事先记录的规则选取、去重错误片段，制作可试听的小样本包，记录角色、起止时间、距离和来源。场景、喊叫、残留及边界异常只有复核后才能标作原因。全量 485 条的未知近邻仅作为待核对线索，不混进有真值的命中率。
4. **根据证据选择改法。** 近邻身份常错，优先检查输入或表示/度量；近邻较好但最终分组仍差，优先检查连接规则；错误集中在某类输入，再对该类做有针对性的对照。近邻失败本身仍不能证明向量中完全没有身份信息。

交付物是一份简短诊断报告、可复现的逐查询/距离记录，以及少量可试听错误实例。报告必须回答“证据更支持哪一环、还缺什么证据”。旧标签只用于定位；选定改法后，再用新片段或新集验证。若以后重切，标签必须重新精确匹配，不能继承旧大段的名字。
