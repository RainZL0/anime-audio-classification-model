## 对白覆盖：现有片段只有约六成对白行

`avs coverage` 用「片段边界应等于字幕行边界」反推偏移（ep01 -0.95 秒、ep02 -0.96 秒，两集片段全部落在字幕行内），再找没有任何片段的对白行。

| | 对白行 | 有片段 | 没片段 | 其中行短于 1 秒 | 其中行够长却没切出 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ep01 | 409 | 243 | 166 | 53 | 113 |
| ep02 | 401 | 243 | 158 | 78 | 80 |

短于 1 秒的那些是切段下限直接筛掉的。够长却没切出的那批混着两种东西：字幕组名、标题卡这类本来就没人念的行，以及确实有人说话却没被检测到的台词（`没人能…追上我`、`帝王果然厉害呢`）。两者比例要人耳听过才知道，音频在 `runs/coverage/<集>/` 下按原因分好了，`lines.txt` 是带台词的清单。

这个缺口不影响「换不换默认分组」——那是在固定片段上比的——但它是重切那条路要解决的问题，也说明现有导出成品最多只能覆盖六成对白。

## 当前证据

在上述 62 条标签中，同角色共有 118 对：67 对已同组，51 对仍分开；不同角色错合为 0 对。51 对漏合集中在 `teo`（39）、`trainer`（6）、`皇帝`（5）、`Nice Nature`（1）。计算口径见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md#评估怎么读)。未标注片段是否混人仍未知。

已经完成的对照没有解决瓶颈：两模型 142 个阈值设置里没有直接换用 WeSpeaker 的证据；少量身份参考的 200 次设置收益有限或新增混人。这些都是同批标签上的探索，不是新集盲测。

## 诊断结论：身份信息在，失败集中在短片段与跨集

嵌入诊断固定 485 条片段、62 条标签，两模型用完全相同的候选池，排除查询自身。12 个角色有 2 条以上标签，构成 49 次查询；13 个单标签角色只当干扰项。完整数字见 [EXPERIMENTS.md](EXPERIMENTS.md#嵌入诊断)。

- **近邻几乎全对。** ReDimNet 的 Top-1 同角色 47/49，Top-3 49/49；WeSpeaker 48/49。两个错例一个只差 0.012，另一个是 `Nice Nature` 仅有的两条标签互相不是最近邻。这不支持“嵌入缺少身份信息”是主因。
- **距离却重叠很宽。** 同人配对 40% 超过 0.5 阈值；异人配对不到 1% 低于 0.5。等错点在 0.636。收紧碎、放宽混，是这条分布本身决定的。
- **全部 51 对漏合都含至少一条短于 1.5 秒的片段**，两模型一致；22 对双方都短，28 对跨集。双方都不短于 1.5 秒的 31 对同人配对没有一对超过阈值。
- **分组规则大体忠实于距离。** 漏合中 38 对本来就超过 0.5，规则改不了；13 对在阈值内却被平均连接拆开。已连接的 67 对最大距离 0.581，错合 0。
- **仍不知道的。** 49 次查询里 30 次在全部 485 条中最近的是未标注片段，只能作线索。可查询角色只有 12 个，跨集可评 26 次。36 条错误实例已导出到 `runs/diagnosis/examples/`，尚未人工试听。近邻正确不等于整个角色能连成一组。

因此证据同时指向两处：短片段（当前是字幕与语音交集，比字幕行短）的表示偏远，以及单一全局平均连接阈值没有利用近邻结构。没有证据支持再换嵌入模型。

**标准连接规则没有收获。** single、complete、mutual_knn 在任何错合水平下都不比 average 找回更多（284 个设置，前沿全是 average）。single 在全池里经未标注片段把角色链成大团；mutual_knn 几乎连不上。详见 [EXPERIMENTS.md](EXPERIMENTS.md#连接规则对照)。

**按整句字幕重切短片段这条路已停。** 短片段对应的整句字幕只比现有片段长约 0.1 秒（中位数），155 条里只有 40 条能多出 0.5 秒以上；短是字幕行本身短。见 [EXPERIMENTS.md](EXPERIMENTS.md#短片段重切的闸门核对)。

**针对短片段的两段式分组是目前唯一有改善的候选。** 长片段先平均连接，短片段再挂到明显最近的组，挂不上的短片段之间再连一次。同阈值 0.50 下由 67 / 0 / 51（正确 / 错合 / 漏合）变为 86 / 0 / 32，`teo` 从 5 组减到 3 组，`皇帝` 与 `Nice Nature` 各合成 1 组；0.51 可到 94 / 0 / 24，但 0.52 起错合陡增到 16 对。分界 1.5 秒与领先幅度 0.05 来自同一批标签，整条曲线也是同批标签上的探索，因此候选没有替换默认分组。见 [EXPERIMENTS.md](EXPERIMENTS.md#两段式分组)。

## 下一步：两集全量重标，再验证两段式候选

**尚未实施。** 候选在旧标签上零错合且多找回 19 对，但分界、幅度和阈值都用了这批标签；在换掉默认分组之前必须用没参与过探索的标签检验，重点是错合。

2026-09-06 改了做法：不再抽样补标，两集 485 条片段全部重标。抽样每条都要重新定位画面，力气大半花在找位置上；而且抽样范围只覆盖候选改动的那部分，别处混没混人始终看不到。整集连着标反而更省力，得到的也是完整验收集而不是一个切片。

1. **两集各标一遍，全量。** 对照画面报名字，顺着时间往下走。

   ```powershell
   uv run avs label runs/episodes/ep01 --archive annotations/ep01-full.json --all --known annotations/names.json
   uv run avs label runs/episodes/ep02 --archive annotations/ep02-full.json --all --known annotations/ep01-full.json --known annotations/names.json
   ```

   ep01 已于 2026-09-06 标完，242 条全部有名字，31 个名字，其中 `__multiple__` 20 条、`__unclear__` 3 条。标 ep02 时先给 ep01 的归档，名字按 ep01 的实际条数排序，ep01 的片段也能在页面上回放对照；`names.json` 放在后面补上没用到的旧名字。跨集同一角色必须同名。标不完可以停，未标的留空。

   ep01 里的解说已经按人分开标成 `解说绿-明坂`、`解说黑-细江`、`男解说`，`names.json` 里的 `解说A`／`解说B`／`解说员`／`橙毛` 是旧写法，ep02 别再用。
2. **旧标签已删除。** `ep01_v4.json` 与 `ep02.json`（62 条时间精确匹配的抽样标签）于 2026-09-06 删除，用过的 27 个角色名提取到了 `annotations/names.json`。评估只用两份 `-full` 归档。EXPERIMENTS 里基于旧标签的数字保留为记录，但已无法重算。
3. **两套分组在新标签上同口径评分。** 跑 `evaluate` 与 `diagnose`，错合与漏合一起报，并按短片段/跨集分层。全量标注之后，未标注片段是否混人这个一直悬着的问题也能一并回答。
4. **决定是否替换默认。** 新标签上错合不增加、漏合减少才替换默认分组与导出；若短片段挂组带来混人，退回 average 并把两段式记为失败。
5. **试听错误实例。** `runs/diagnosis/examples/`，确认远距离同人对里是否有喊叫、残留或边界异常。
6. **新集。** 第 3 集起用新流程（整句字幕切段）准备，先按同样方法标注，再作为独立验证。

`avs label-plan` 与 `runs/label-plan.json` 是抽样补标那条路留下的，全量重标之后用不上了，留着备查。
