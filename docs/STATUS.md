## 分界线漂移：形状量出来了，也有了一个待检验的对策

**结论先说：池子变大并没有让分组变差，是固定的那个数字在自己的取舍曲线上滑。** `avs drift` 把中间的九档池子都跑了，每档随机抽 8 遍，被打分的那一集始终整集在池子里。三集各跑一份，报告在 `runs/drift-ep0*.json`，数字见 [EXPERIMENTS.md](EXPERIMENTS.md#池子变大到底发生了什么是分界线滑了不是成绩掉了)。

1. **固定 0.70 时连上和错误合并一起往下掉**（第 3 集 2613/76 → 2095/21）。两个数同向走，说明是分界线偏紧了，不是认错了人。
2. **把错误合并按住不动、让分界线自由挪，池子越大连上的反而越多**（第 3 集 ≤76 这一档，2613 → 3278）。**能达到的取舍曲线不退化。**
3. 要守住位置，分界线得随池子往外挪 4% 至 11%，幅度逐渐收窄。

对策是**按池子自己的距离定分界线**：分界线 = 1.275 × 池子内全部配对距离的第 1 百分位。这个量随池子变大 +8.2%，方向和幅度都对；配对距离中位数、最近邻距离、合并高度、固定组数占比都试过，方向不对或几乎不动。

倍数 1.275 定在「现在三集 1176 条池子上正好乘出 0.70」，所以**今天分出来的组和固定 0.70 一模一样**（1184 条归属逐条核对过），分岔要等语料长大才开始。第 3 集上这条线从 1950/18 到 2221/31 基本不动，而固定那条从 2613/76 滑到 2095/21。

命令行是 `avs group --relative`，**默认仍然是固定 0.70**，因为倍数和分位都是在已有三集的标签上挑的，还没有独立检验。

## 已经定下、不要再讨论的

- **切片段按整条字幕行。** 旧做法是拿语音检测结果和字幕求重叠再切，丢掉了四成对白行（第 1 集 409 行里 166 行没有片段，第 2 集 401 行里 158 行）。新做法在第 3 集做到 375 行全覆盖。
- **不再用模型判断片段里有没有人说话**，也不用模型区分角色说话和环境人声。字幕会给电视解说、群体欢呼这类不属于角色的声音配字，这些照常收进片段表，标注时由人打上「不是说话」之类的标签。
- **短于 0.5 秒的片段不算声纹、不进分组。** 第 3 集实测这一档排序正确率只有 0.61，完全随机是 0.50。丢掉之后第 3 集的错误合并从 25 降到 21，连上的还多了 4 对。音频照样切得出来。
- **模型用 `anime-va`，分界线 0.70。** 第 3 集独立检验通过。
- **前两集不重切。** 重切会让 485 条人工标签全部作废，而新旧两种切法孰优已经不需要靠它裁决。

## 已经排除、不要重开的

这些都试过并留下了数据，见 EXPERIMENTS。

| 试过什么 | 结果 |
| --- | --- |
| 换成 WeSpeaker | 没有一个设置能压过 `redimnet2-b6` |
| 按最近一对 / 按最远一对 / 互相都是对方最近邻 这三种合并规则 | 都不如按整组平均距离合并 |
| 少量身份参考 | 收益有限，还会把原组里混进的错人一起传播出去 |
| 把短片段按整句字幕重切 | 整句只比原片段长约 0.1 秒，短是字幕行本身短 |
| 分两步的分组做法（长片段先分组，短片段再挂上去） | 在全量标签上错误合并 1057 对，对照的 146 对，明显更差 |
| 分数归一化 | 排序正确率只涨 0.0022，最该受益的短片段反而更差 |
| 给短片段补上前后相邻音频 | 补到 1.5 秒只涨 0.0018，补到 3 秒明显变坏 |
| 按字幕定位标记筛掉招牌和字幕组名 | 三集里带定位标记的行绝大多数是真台词，这个过滤器会丢掉正片内容 |

## 下一步

1. **第 4 集是按池子定分界线的独立检验。** 口径**现在就定死**：先跑 `avs prepare`、`embed`、`label --all` 把第 4 集整集标完，再用四集一起分组，只在第 4 集的配对上打分，固定 0.70 和 `--relative` 各出一份。**通过的标准是错误合并停在同一水平**（三集上 `--relative` 是 18 到 31，固定 0.70 是 76 滑到 21），不是连上的对数好看。标注之前不看任何一版分组结果。
2. **往外推那一段仍然没有数据。** 规则是在 372 到 1176 条之间对上的，13 集大约 5000 条。每加一集就重跑一次 `avs drift`，看第 1 百分位是不是还在按同样的方式走。
3. **补标第 1、2 集的 324 条。** 现在只剩一个用途：看 0.5 到 1 秒这一档在更多数据上是不是同样勉强（第 3 集实测排序正确率 0.81）。
4. **微调模型仍不在计划内。** 现在 860 条标签、34 个角色、三集，规模不够，而且换现成模型这条路刚证明还有空间。
5. **按当前分组重跑导出。** 分组换了模型和分界线之后一直没重跑。
