## 全量标签验收

两集 485 条片段全部对照画面标了名字（ep01 242 条、ep02 243 条），其中 445 条是人名、40 条是 `__multiple__` / `__unclear__`。这是第一次在完整数据上验收：以前「未标注片段有没有混人」只能承认不知道，现在错合是量出来的，不是下限。

| --- | ---: | ---: | ---: |

## 分数归一化：没有用

全量诊断显示同人距离随片段变短、跨集而系统性变大，猜想是「短片段跟谁都不太像」这种整体
偏移，靠分数归一化（先看这条片段跟一堆无关片段有多像，再问这一对比它平常的水平高出多少）
应当能修。先只量分离度，不接进聚类：规则改不了分数本身，分不开就没必要往下做。

98790 对标签配对，ReDimNet：

| 归一化 | 总体 AUC | 等错率 | 0-1.5 秒 AUC | 1.5-3 秒 | 3-6 秒 | 跨集 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 无（原始余弦） | 0.9296 | 0.1412 | 0.9239 | 0.9430 | 0.9402 | 0.9215 |
| snorm（全体干扰集） | 0.9318 | 0.1414 | 0.9216 | 0.9467 | 0.9507 | 0.9222 |
| asnorm（最像的 100 条） | 0.9000 | 0.1790 | 0.8824 | 0.9250 | 0.9278 | 0.8842 |

**猜想不成立。** snorm 总体 AUC 只涨 0.0022，等错率反而从 0.1412 变成 0.1414；本该受益最多的
短片段还退了一点（0.9239 → 0.9216），跨集几乎不动（0.9215 → 0.9222）。真正变好的是长片段，
而长片段本来就不是问题。asnorm 全面更差，原因清楚：没有独立干扰集，「最像的 100 条」里
混进了同角色片段，等于拿同人分数去当基准。

结论是短片段的劣势不是标定问题，而是信息真的少了，归一化修不回来。这条路不接进分组。

WeSpeaker 上 snorm 确实有效（AUC 0.8774 → 0.8922，等错率 0.1932 → 0.1778），但归一化后仍然
低于 ReDimNet 未归一化的 0.9296，不改变主模型选择。

记录在 `runs/score-norm.json`，命令是 `avs scores`。

固定 485 条片段、62 条精确标签、两模型缓存，不重跑音频模型。候选池是全部标签片段，排除查询自身；只有一条标签的 13 个角色不作查询，但留作干扰项。12 个角色有 2 条以上标签，共 49 次查询，其中 20 条短于 1.5 秒。两模型用同一候选池；分组对照取当前 `runs/groups/uma.json`。

## 连接规则对照

固定同样的 485 条片段、62 条标签与 ReDimNet 缓存，在 0.20—0.90（步长 0.01）上比较四种连接规则，共 284 个设置。规则只改变“哪些距离算连上”，声纹与距离不变。

| 规则 | 零错合时找回最多的设置 | 正确连接 | 漏合 | 全量组数 |
| --- | ---: | ---: | ---: | ---: |
| average（现行） | 0.51 | 75 | 43 | 90 |
| complete | 0.66 | 51 | 67 | 66 |
| single | 0.26 | 27 | 91 | 319 |
| mutual_knn（k=3，互为近邻才连边） | 0.49 | 25 | 93 | 264 |

“错合更少且正确连接不更少”的前沿共 8 个设置，全部是 average。single 在 0.40 就产生 271 对错合，0.50 时 705 对：全池里未标注片段把不同角色链成大团。mutual_knn 从 0.55 起完全不再变化（25 对正确、3 对错合、263 组）：标签片段在全池中的近邻多为未标注片段，且互为近邻的要求让连通分量停在两三条。complete 零错合能维持到 0.66，但找回始终少于 average。

结论：在当前片段与嵌入上，换这三种标准连接规则不能收回漏合。

## 短片段重切的闸门核对

用当前片段反推两集字幕偏移（ep01 −0.96 秒、ep02 −0.97 秒，重合度 0.61/0.65），把 155 条短于 1.5 秒的片段各自对到重合最多的整句字幕行：整句只比现有片段长 0.08/0.11 秒（中位数），能多出 0.5 秒以上的只有 40 条，多出 1 秒以上的 25 条。短片段短是因为字幕行本身短，不是交集切法削掉的。按整句重切不能给大多数短片段补回声音，这条路在动手前停止。

## 两段式分组

诊断指出漏合全部含短片段，而短片段在标签候选里的最近邻仍几乎全对，于是单独处理它们：先只用不短于 1.5 秒的 330 条做平均连接，再把 155 条短片段挂到“最近成员距离不超过阈值、且领先第二近的组至少 0.05”的组，挂不上的短片段之间再做一次平均连接（否则只有短片段的角色永远连不起来，`路人2` 的三条就是这种情况）。1.5 秒与 0.05 都是常量，只扫描阈值；同一批 62 条标签、ReDimNet 缓存，71 个设置。

| 阈值 | two_stage 正确 / 错合 / 漏合 / 全量组数 | average 正确 / 错合 / 漏合 / 全量组数 |
| ---: | ---: | ---: |
| 0.45 | 72 / 0 / 46 / 117 | 50 / 0 / 68 / 141 |
| 0.49 | 79 / 0 / 39 / 100 | 67 / 0 / 51 / 107 |
| 0.50 | 86 / 0 / 32 / 91 | 67 / 0 / 51 / 100 |
| 0.51 | 94 / 0 / 24 / 80 | 75 / 0 / 43 / 90 |
| 0.52 | 94 / 16 / 24 / 73 | 80 / 2 / 38 / 81 |
| 0.55 | 118 / 76 / 0 / 53 | 86 / 16 / 32 / 61 |

零错合下 two_stage 最多找回 94 对（0.51），average 75 对（0.51）。two_stage 在 0.52 起错合陡增到 16 对，因为长片段之间的平均连接从这里开始混人；可用区间很窄。在角色名统一之前，0.50 的候选曾显示 1 对“错合”（1.25 秒的 `Nice Nature` 挂进 4.1 秒的 `红毛` 组，距离 0.474），实际是同一角色，这条挂组是对的。

固定候选取现行阈值 0.50：正确 86 对、错合 0 对、漏合 32 对，91 组、50 个单条组；`teo` 从 5 组减到 3 组，`皇帝` 与 `Nice Nature` 各合成 1 组，`trainer` 仍 2 组。剩余 32 对漏合（`teo` 26、`trainer` 6）全部含短片段，15 对双方都短，18 对跨集，只有 6 对在阈值内。155 条短片段里 123 条被挂进多条组，这些归属绝大多数没有人工标签。

候选未替换默认分组和导出：短/长分界和领先幅度来自同一批标签的诊断，阈值曲线也在同批标签上扫出，属于探索，不是验证。

## 证据的边界

人工标签只覆盖一小部分声音；旧标签此前已用于探索。阈值扫描、重复参考划分都不是新集盲测，配对也彼此相关。实验不支持直接采用这些候选，但不能证明所有表示、度量、聚类或参考方法都无效。诊断的近邻命中率只在 61 条标签候选里成立，全池近邻多为未标注片段；可查询角色 12 个、跨集可评 26 次，结论只够定位问题，不够验收改法。
