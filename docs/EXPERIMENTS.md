# 已完成实验与证据

这里只记录已完成的实验，不维护下一步计划。当前状态与假设见 [STATUS.md](STATUS.md)。以下数字都来自同样的旧字幕交集片段，不能用来声称直接字幕整句切法已验证。

## 双模型与阈值对照

固定 485 条片段、62 条精确人工身份标签，以全局平均连接分别扫描余弦距离 0.20—0.90，步长 0.01，共 142 个设置。

| 模型与阈值 | 全量组数 | 错合配对 | 漏合配对 | 同人配对找回率 |
| --- | ---: | ---: | ---: | ---: |
| ReDimNet 0.50（基线） | 100 | 0 | 50 | 57.26% |
| WeSpeaker 0.45（扫描中零错合的最高找回率） | 193 | 0 | 86 | 26.50% |
| ReDimNet 0.52 | 81 | 3 | 38 | 67.52% |
| WeSpeaker 0.60 | 81 | 5 | 46 | 60.68% |

此次扫描中，WeSpeaker 的每个设置都存在一个 ReDimNet 设置，错合不更多、正确连接不少，且至少一项更好。没有直接替换主模型的证据。

ReDimNet 0.52 多连回 12 对，同时新增 3 对错合：`teo / 漩涡` 两对、`红毛 / Nice Nature` 一对。WeSpeaker 0.60 找回基线漏掉的 15 对，又丢失基线已连对的 11 对，并新增 5 对错合；有不同线索，不等于融合会更好。

## 少量身份参考

角色固定为 `teo`、`trainer`、`皇帝`，每人取 1 条或 2 条人工参考，各用种子 0—19 划分。参考全部排除评分，原分组也在完全相同的剩余片段上评分。方法细节见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md#参考实验)。

**连接含同名参考的原组**：共 40 次。每人 1 条不能连接两个原组，没有改善；每人 2 条，20 次中仅 3 次减少剩余样本漏合，平均从 30.25 对降到 29.50 对，评分样本中错合为 0，全量平均 98.7 组。效果有限；原组内未标注的混人可能被一起传播。

**逐片段按最近参考归属**：四个距离阈值，另要求领先第二个参考角色至少 0.05，共 160 次。以下是每人 2 条参考、20 次划分的平均值：

| 距离阈值 | 同批评分片段的基线漏合 | 参考法漏合 | 参考法错合 |
| --- | ---: | ---: | ---: |
| 0.30 | 30.25 | 37.95 | 0 |
| 0.40 | 30.25 | 37.20 | 2.60 |
| 0.50 | 30.25 | 27.75 | 11.90 |
| 0.60 | 30.25 | 11.85 | 83.20 |

严格时可能拆开原本正确的组，宽松时新增混人，未得到可采用的整体改善。每人 1 条的完整结果同样保存在报告中。

候选事先固定每人 2 条、种子 0，最近参考法还固定距离 0.50。排除 6 条参考后剩余 56 条：

| 方法 | 错合 | 漏合 |
| --- | ---: | ---: |
| 同批片段的原分组 | 0 | 25 |
| 连接参考所在组 | 0 | 25 |
| 最近参考归属 | 3 | 32 |

这里的 25 对不能与全部 62 条标签的 50 对直接比较，评分集合不同。候选未替换默认分组和导出。

## 证据的边界

人工标签只覆盖一小部分声音；旧标签此前已用于探索。阈值扫描、重复参考划分都不是新集盲测，配对也彼此相关。实验不支持直接采用这些候选，但不能证明所有表示、度量、聚类或参考方法都无效。嵌入近邻诊断尚未完成，不应从这些分组成绩跳到根因结论。
