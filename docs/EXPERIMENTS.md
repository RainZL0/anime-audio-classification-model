## 全量标签验收

两集 485 条片段全部对照画面标了名字（ep01 242 条、ep02 243 条），其中 445 条是人名、40 条是 `__multiple__` / `__unclear__`。这是第一次在完整数据上验收：以前「未标注片段有没有混人」只能承认不知道，现在错合是量出来的，不是下限。

### 两段式候选没有通过

| 分组（阈值 0.50） | 正确 | 错合 | 漏合 |
| --- | ---: | ---: | ---: |
| average（现行默认） | 5745 | **68** | 4876 |
| two_stage（候选） | 6364 | **1057** | 4257 |

候选多找回 619 对，代价是多出 989 对错合。其中 870 对来自同一处：two_stage 把 87 条 `teo` 和 10 条 `大和赤骥` 并进了同一组 `speaker_013`，average 下这两个角色从不同组。剔掉这一处，错合仍是 187 对 68。

剔除 `路人`、`医生`、`老师`、`理发师`、`奶茶店`、`旁白` 这些可能是集合名而非单一角色的标签后（剩 408 条），结论不变：average 5699 / 66 / 4679，two_stage 6317 / 1016 / 4061。

| ---: | ---: | ---: | --- |

差距小且随阈值反复，不构成替换默认的理由。**结论：保留 average 0.50，两段式这条路关闭。**

### 现在的实际水平

ReDimNet 在 445 条标签上：同人配对 10621 对、异人配对 88169 对，配对排序正确率 0.9296，两类错误相等的那一点在距离 0.632（各 14.1%）。默认设置 0.50 下同人配对找回率 54%，也就是说同一角色的片段有近一半仍然分在不同组。

| 记录 | 本地位置 |
| --- | --- |
| 两套分组的全量评分 | `runs/groups/uma-full-evaluation.json`、`uma-two-stage-full-evaluation.json` |

下面反复出现两个衡量指标，先说清楚它们是什么：

- **排序正确率**：随机拿一对「同一角色」的片段和一对「不同角色」的片段，同一角色那对距离更近的比例。完全随机是 0.50，完美是 1.00。
- **相等错误率**：把分界线挪到「同一角色被错误分开」和「不同角色被错误合并」这两种错误一样多的位置，那时候的错误率。越小越好。

## 第 3 集盲测：模型换对了，但增益比调参用的前两集上小得多

ep03 375 条全部标完（306 条人名、69 条特殊标签、19 个角色），是全项目第一份没参与过任何调参的数据。评分口径在标注之前就写死在 STATUS 里：三集一起分组，只在 ep03 的配对上评分。

**预先约定的对照**（固定阈值，阈值来自前两集）：

| 模型 | 阈值 | 正确 | 错合 | 漏合 | 找回率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| redimnet2-b6 | 0.50 | 2082 | 63 | 3182 | 39.6% |
| anime-va | 0.70 | 2091 | **25** | 3173 | 39.7% |

**调参用的前两集上的增益没有兑现。** 前两集上 anime-va 多连回 504 对，盲测只多 9 对，找回率差距从 4.8 个百分点缩到 0.2。兑现的是另一半：错合从 63 降到 25，少了六成。

**但换个口径 anime-va 又是压倒性的。** ep03 单独成池、扫阈值（只作说明用的对照，非预先约定）：

| 错合上限 | redimnet2-b6 | anime-va |
| ---: | ---: | ---: |
| ≤25 | 1376 @0.42 | **2105** @0.67 |
| ≤63 | 1766 @0.46 | **2477** @0.69 |
| ≤120 | 1919 @0.49 | **3259** @0.77 |
| ≤250 | 2437 @0.55 | **3423** @0.79 |

两个口径都支持换模型，只是幅度差别很大。取信预先约定的那个：anime-va 更好，但主要好在少犯错，不在多连对。

### 阈值会随片段池增大而漂移

同一个阈值，池子越大合并越保守——平均连接要求整簇平均距离达标，簇一大平均就上去了：

| 模型 @阈值 | ep03 单独成池（375 条） | 三集合池（1184 条） |
| --- | ---: | ---: |
| redimnet2-b6 @0.50 | 正确 2059 / 错合 146 | 正确 2082 / 错合 63 |
| anime-va @0.70 | 正确 2613 / 错合 80 | 正确 2091 / 错合 25 |

anime-va 在合池后掉了 522 对。**这说明单一全局距离阈值不是个常数**，语料从 3 集长到 13 集时会继续漂。预先约定的对照因此对 anime-va 不利：0.70 在 375 条池上接近最优，放进 1184 条池就偏紧了。这是结构性问题，不是调参问题。

### 一秒以下的片段几乎没有用

ep03 是第一份含 1 秒以下片段的标注，这个问题终于量得出来了：

| 最短片段时长 | 同人配对 | redimnet2-b6 排序正确率 / 错误率 | anime-va 排序正确率 / 错误率 |
| --- | ---: | ---: | ---: |
| 0-0.5 秒 | 130 | 0.6113 / 0.415 | 0.5500 / 0.478 |
| 0.5-1 秒 | 1105 | 0.8068 / 0.271 | 0.8252 / 0.257 |
| 1-1.5 秒 | 1791 | 0.8989 / 0.177 | 0.8725 / 0.206 |
| 1.5-3 秒 | 2015 | 0.8975 / 0.184 | 0.9032 / 0.161 |
| 3-6 秒 | 223 | 0.9590 / 0.081 | 0.9502 / 0.081 |

0-0.5 秒那一档 排序正确率 0.61，随机是 0.50，基本是废的；0.5-1 秒 0.81 也很弱。**这修正了之前「片段短不是主要矛盾」的说法**——那句话是在最短 1.0 秒的数据上得出的，1 秒以下的悬崖当时根本看不见。1 秒以上的部分那句话仍然成立。

### 一个待定的疑点：按整条字幕行切法可能不如按字幕与语音检测的重叠部分切法

同样是 1.5-3 秒这一档，ep03（按整条字幕行切）ReDimNet 是 0.8975，前两集（按字幕与语音检测的重叠部分切）是 0.9430。整行包含台词前后的静音和杂音，稀释了指纹，这是个合理的解释，但集与集本身也有差异，两者混在一起分不开。要判定得靠前两集后补的 324 条整行片段——它们和旧片段同集同时长档，标完就能直接比。

## 换成动画域模型：第一个真正有效的改动

前面所有尝试都是不动模型的，全部无效。这次换模型：[anime_speaker_embedding](https://github.com/litagin02/anime_speaker_embedding)（litagin02，MIT），ECAPA-TDNN 把 BatchNorm 换成 GroupNorm，在约 700 万条视觉小说音频上训练，输出 192 维。两个变体：`char` 按角色训练（7357 个角色），`va` 按声优训练（989 位声优）。原有两个模型都是在 VoxCeleb 上训的说话人验证模型，训练素材是英语为主的真人访谈。

809 条片段、445 条标签、98790 对配对，同一套代码路径：

| 模型 | 排序正确率 | 相等错误率 | 1-1.5 秒 | 1.5-3 秒 | 3-6 秒 | 跨集 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| redimnet2-b6（原主模型） | 0.9296 | 0.1412 | 0.9239 | 0.9430 | 0.9402 | 0.9215 |
| anime-char | 0.9274 | 0.1439 | 0.9209 | 0.9456 | 0.9828 | 0.9164 |
| **anime-va** | **0.9441** | **0.1244** | **0.9382** | **0.9545** | **0.9851** | **0.9382** |

**按角色训练的 `char` 反而不如按声优训练的 `va`。** 一个解释是本作里同一声优配多角的情况不多，角色身份基本等同于声优身份，而 `char` 那种「积极区分」的训练目标会把同一角色在不同情绪下的声音也推开。

端到端分组（average 连接，同一片段池，错合预算 ≤68）：

| 模型 | 阈值 | 正确 | 错合 | 漏合 | 找回率 | 组数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| redimnet2-b6 | 0.50 | 5601 | 64 | 5020 | 52.7% | 215 |
| anime-char | 0.53 | 4383 | 46 | — | 41.3% | 302 |
| **anime-va** | **0.70** | **6105** | **53** | **4516** | **57.5%** | **195** |

anime-va 多连回 504 对，错合还少 11 对。放宽预算差距更大：错合 ≤600 时 7662 对 5780，≤1200 时 9598 对 6315。

**阈值不能照搬。** 作者提醒该模型「倾向于积极区分说话人」，实测同人相似度中位 0.337，而 ReDimNet 是 0.541，换算成距离是 0.663 对 0.460。原来 0.20—0.90 的扫描区间对它几乎全无意义，`avs compare` 因此加了 `--low` / `--high`。

anime-va 在 0.70 的 53 对错合分布在 13 种角色组合上，最大的一处是 `suzuka / 丸善斯基` 12 对，`丸善斯基` 另外还和 `麦昆` 错合 9 对——同一声优配多角正是这个变体的预期失败模式。

**这仍然是同一批标签上的调参。** 模型本身没在我们的数据上训练过，所以模型之间的比较受过拟合影响较小；但 0.70 这个阈值是在这批标签上选的，要等第 3 集盲测才算数。

## 给短片段补上前后相邻音频：也没有用

另一个不动模型的猜想：短片段指纹差是因为模型听到的音太少，那就向两侧借相邻音频补足，
片段本身的时间范围不变，只是模型多听一点上下文。ReDimNet，两集 485 条固定片段：

| 最小窗口 | 排序正确率 | 相等错误率 | 1-1.5 秒 | 1.5-3 秒 | 3-6 秒 | 跨集 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0（现行） | 0.9296 | 0.1412 | 0.9239 / 0.147 | 0.9430 / 0.126 | 0.9402 / 0.137 | 0.9215 |
| 1.5 秒 | 0.9317 | 0.1386 | 0.9257 / 0.144 | 0.9430 / 0.126 | 0.9402 / 0.137 | 0.9242 |
| 2.0 秒 | 0.9309 | 0.1432 | 0.9231 / 0.151 | 0.9435 / 0.129 | 0.9402 / 0.137 | 0.9245 |
| 3.0 秒 | 0.9175 | 0.1668 | 0.8982 / 0.188 | 0.9402 / 0.137 | 0.9402 / 0.137 | 0.9112 |

窗口 1.5 秒时短片段那一档由 0.9239 涨到 0.9257，长片段两档一个数都没变——它们本来就不需要
补，这正好当了对照，说明变化确实来自补音而非别处。但涨幅只有 0.0018，和归一化一个量级，
等于没有。再往上补就开始变坏：2 秒已经拖累短片段，3 秒把它打到 0.8982，因为借来的音里
越来越多是别人在说话。

**两个不动模型的猜想都试完了，都不成立。** 短片段的劣势既不是分数标定，也不是上下文不够。

## 分数归一化：没有用

全量诊断显示同人距离随片段变短、跨集而系统性变大，猜想是「短片段跟谁都不太像」这种整体
偏移，靠分数归一化（先看这条片段跟一堆无关片段有多像，再问这一对比它平常的水平高出多少）
应当能修。先只量分离度，不接进聚类：规则改不了分数本身，分不开就没必要往下做。

98790 对标签配对，ReDimNet：

| 归一化 | 排序正确率 | 相等错误率 | 0-1.5 秒 | 1.5-3 秒 | 3-6 秒 | 跨集 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 无（原始余弦） | 0.9296 | 0.1412 | 0.9239 | 0.9430 | 0.9402 | 0.9215 |
| snorm（全体拿来作基准的无关片段） | 0.9318 | 0.1414 | 0.9216 | 0.9467 | 0.9507 | 0.9222 |
| asnorm（最像的 100 条） | 0.9000 | 0.1790 | 0.8824 | 0.9250 | 0.9278 | 0.8842 |

**猜想不成立。** snorm 总体排序正确率 只涨 0.0022，两类错误相等时的错误率反而从 0.1412 变成 0.1414；本该受益最多的
短片段还退了一点（0.9239 → 0.9216），跨集几乎不动（0.9215 → 0.9222）。真正变好的是长片段，
而长片段本来就不是问题。asnorm 全面更差，原因清楚：没有独立拿来作基准的无关片段，「最像的 100 条」里
混进了同角色片段，等于拿同人分数去当基准。

结论是短片段的劣势不是标定问题，而是信息真的少了，归一化修不回来。这条路不接进分组。

WeSpeaker 上 snorm 确实有效（排序正确率 0.8774 → 0.8922，两类错误相等时的错误率 0.1932 → 0.1778），但归一化后仍然
低于 ReDimNet 未归一化的 0.9296，不改变主模型选择。

记录在 `runs/score-norm.json`，命令是 `avs scores`。

## 少量身份参考

角色固定为 `teo`、`trainer`、`皇帝`，每人取 1 条或 2 条人工参考，各用种子 0—19 划分。参考全部排除评分，原分组也在完全相同的剩余片段上评分。方法细节见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md#参考实验)。

## 连接规则对照

固定同样的 485 条片段、62 条标签与 ReDimNet 缓存，在 0.20—0.90（步长 0.01）上比较四种连接规则，共 284 个设置。规则只改变“哪些距离算连上”，声纹与距离不变。

| 规则 | 零错合时找回最多的设置 | 正确连接 | 漏合 | 全量组数 |
| --- | ---: | ---: | ---: | ---: |
| average（现行） | 0.51 | 75 | 43 | 90 |
| complete | 0.66 | 51 | 67 | 66 |
| single | 0.26 | 27 | 91 | 319 |
| mutual_knn（k=3，互为近邻才连边） | 0.49 | 25 | 93 | 264 |

“错合更少且正确连接不更少”的前沿共 8 个设置，全部是 average。single 在 0.40 就产生 271 对错合，0.50 时 705 对：全池里未标注片段把不同角色链成大团。mutual_knn 从 0.55 起完全不再变化（25 对正确、3 对错合、263 组）：标签片段在全池中的近邻多为未标注片段，且互为近邻的要求让连通分量停在两三条。complete 零错合能维持到 0.66，但找回始终少于 average。

结论：在当前片段与嵌入上，换这三种标准连接规则不能收回漏合。

## 短片段重切的闸门核对

用当前片段反推两集字幕偏移（ep01 −0.96 秒、ep02 −0.97 秒，重合度 0.61/0.65），把 155 条短于 1.5 秒的片段各自对到重合最多的整句字幕行：整句只比现有片段长 0.08/0.11 秒（中位数），能多出 0.5 秒以上的只有 40 条，多出 1 秒以上的 25 条。短片段短是因为字幕行本身短，不是按字幕与语音检测的重叠部分切法削掉的。按整句重切不能给大多数短片段补回声音，这条路在动手前停止。

## 两段式分组

诊断指出漏合全部含短片段，而短片段在标签候选里的最近邻仍几乎全对，于是单独处理它们：先只用不短于 1.5 秒的 330 条做平均连接，再把 155 条短片段挂到“最近成员距离不超过阈值、且领先第二近的组至少 0.05”的组，挂不上的短片段之间再做一次平均连接（否则只有短片段的角色永远连不起来，`路人2` 的三条就是这种情况）。1.5 秒与 0.05 都是常量，只扫描阈值；同一批 62 条标签、ReDimNet 缓存，71 个设置。

| 阈值 | two_stage 正确 / 错合 / 漏合 / 全量组数 | average 正确 / 错合 / 漏合 / 全量组数 |
| ---: | ---: | ---: |
| 0.45 | 72 / 0 / 46 / 117 | 50 / 0 / 68 / 141 |
| 0.49 | 79 / 0 / 39 / 100 | 67 / 0 / 51 / 107 |
| 0.50 | 86 / 0 / 32 / 91 | 67 / 0 / 51 / 100 |
| 0.51 | 94 / 0 / 24 / 80 | 75 / 0 / 43 / 90 |
| 0.52 | 94 / 16 / 24 / 73 | 80 / 2 / 38 / 81 |
| 0.55 | 118 / 76 / 0 / 53 | 86 / 16 / 32 / 61 |

零错合下 two_stage 最多找回 94 对（0.51），average 75 对（0.51）。two_stage 在 0.52 起错合陡增到 16 对，因为长片段之间的平均连接从这里开始混人；可用区间很窄。在角色名统一之前，0.50 的候选曾显示 1 对“错合”（1.25 秒的 `Nice Nature` 挂进 4.1 秒的 `红毛` 组，距离 0.474），实际是同一角色，这条挂组是对的。

固定候选取现行阈值 0.50：正确 86 对、错合 0 对、漏合 32 对，91 组、50 个单条组；`teo` 从 5 组减到 3 组，`皇帝` 与 `Nice Nature` 各合成 1 组，`trainer` 仍 2 组。剩余 32 对漏合（`teo` 26、`trainer` 6）全部含短片段，15 对双方都短，18 对跨集，只有 6 对在阈值内。155 条短片段里 123 条被挂进多条组，这些归属绝大多数没有人工标签。

候选未替换默认分组和导出：短/长分界和领先幅度来自同一批标签的诊断，阈值曲线也在同批标签上扫出，属于探索，不是验证。

## 证据的边界

人工标签只覆盖一小部分声音；旧标签此前已用于探索。阈值扫描、重复参考划分都不是新集盲测，配对也彼此相关。实验不支持直接采用这些候选，但不能证明所有表示、度量、聚类或参考方法都无效。诊断的近邻命中率只在 61 条标签候选里成立，全池近邻多为未标注片段；可查询角色 12 个、跨集可评 26 次，结论只够定位问题，不够验收改法。
