# 保留的约束与教训

这里只保留会影响后续判断的内容。当前方案见 [STATUS.md](STATUS.md)，近期实测见 [EXPERIMENTS.md](EXPERIMENTS.md)。

## 目标和数据底线

- 收集单位是角色，不是配音演员；允许出现新角色，不把未知角色强塞给几个已知身份。
- 需要的是声音素材，字幕提供时间边界；不需要为此增加转写或文字识别流程。
- 当前先解决身份分类，语气词、噪声后置。单人语音是工作假设，不是已通过音质检测。
- 原始素材、对照画面的人工记录、有效模型和昂贵缓存必须保留。分析用 16 kHz，导出从原采样率人声轨切；升采样不能补回丢失的高频。
- 所有片段走同一套处理，全部抽人声，不逐条挑“干净的就用原音轨”。数据集内部一致比单条片段的绝对音质重要。
- 62 条抽样标签上「零错合、漏合全是短片段」的结论，在 485 条全量标签下全部不成立（错合 68 对，双方都不短于 1.5 秒的同人配对仍有 27.6% 连不上）。样本小到某个数是 0 的时候，那个 0 说明的是样本，不是系统。用它调出来的参数（two_stage 的 1.5 秒分界、0.05 领先幅度）在全量标签上把错合推到 1057 对。
- 同一批标签既调参又验收，看不出问题；换一批标签才看得出。两段式在旧标签上「零错合多找回 19 对」，在全量标签上多出 989 对错合，其中 870 对来自把两个角色并成一组这一处失误。
- 片段 ID 是集名加时间范围的哈希，跟邻居无关，所以往片段表里只增不改能保住已有标签。补片段用这个性质，重切则没有这个便宜可占。
- 想用「字幕带定位标记」筛掉招牌和字幕组名之前先数一遍：三集里带定位的 Default 行绝大多数是真台词，这个过滤器会丢掉正片内容。
- 没参与过调参的那一集要在标注之前就把评分口径写死。ep03 标完后 anime-va 在两个口径下差别很大（预先约定的三集合池只多 9 对，描述性的单集池多 711 对），先定口径才没有挑对自己有利那一种的余地。
- 调参用的前两集上的增益会缩水。anime-va 在前两集上多连回 504 对，盲测只多 9 对；兑现的是另一半，错合少了六成。换模型这个决定是对的，但幅度别信调参用的前两集。
- 平均连接下的全局距离阈值不是常数：池子越大，整簇平均距离越难达标，同一阈值合并越保守。语料会增长的系统里，「调一个阈值」本身就是个会过期的答案。
- 各集分别标注时，同一角色在每集必须用同一个名字。ep01 的 `红毛` 和 ep02 的 `Nice Nature` 曾被评估当成两个人，把一次正确的挂组记成了错合。新集标注前先对照已有名字表。

## 不重复的错误

1. **机器标签不能当真值。** 给机器组起多数标签再给它评分，会掩盖组内混人。只用人工对照画面确认的身份；支持样本排除评分，两种方法对照同一剩余集合。
2. **旧范围标签不能贴到新范围。** 曾把旧大段身份用于新小段，夸大了评估覆盖；旧“75 条、0.930”等分数不作当前验收依据。重切后重新精确匹配。
3. **配对与抽样不是独立观察。** 同角色多条声音会组合出很多配对；换参考后的评分集也改变，不能把漏合数下降直接当改进。旧标签反复试方法仍是探索。
4. **中心点会固化上游错误。** 曾把混人原组直接平均，又把片段阈值搬到中心点，导致大量错合。当前全局分组不采用机器身份标签或两层中心点合并。
5. **质量排名不能保证身份或纯净。** 前 50% 配额仍会漏过语气词、音效，也会丢掉可用片段。该路线与相关依赖已移除；小组不能全部吞进同一杂项桶。
6. **字幕一直是可用输入。** 曾误记成没有字幕而绕路。当前已有两集使用字幕交集边界，新流程直接采用对齐后的字幕行；二者不能混称为同一切法。
7. **听音记忆负担不是音质问题。** 早期凭耳朵分组有近半标不清，对照画面报名字才有可用身份真值。旧现场记录保留，但不把听音组号升级为真值。
8. **卡拉 OK 分离不按人物分离。** 主唱/和声两边仍有多人，不能当目标说话人提取；该模型已删除。
9. **零错合不等于成功。** 每句单独成组也能零错合；必须一起看漏合、组数及未标注覆盖。整组传播参考标签也可能把隐藏的错人一起带过去。
10. **不从结果跳到根因。** 换模型或参考法未改善，不足以证明嵌入一定无效；情绪、短句、边界都需实测。先诊断当前表示，再选择改哪一环，避免轮流试模型和阈值。
11. **近邻正确不等于能靠近邻连组。** 标签片段的最近标签片段几乎总是同角色，但在 485 条全池里最近的多是未标注片段：单连接会经它们把角色链成大团，互为近邻规则又几乎连不上。全池里的链式传播必须用人工标签的错合来检验，不能只看标签子集的近邻命中。
12. **快问快答式对白的边界误差会把邻座切进片段。** 第 1 集曾测得 44% 的检测语音段与前一段换人且间隔不到 0.25 秒；说话时间线的“无重叠”只保证标签不重叠，音频里另一个人仍在。诊断“边界异常”时要实际试听，不能只看时间线标注。
