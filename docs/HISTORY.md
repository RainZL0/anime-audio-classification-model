# 必须保留的约束与教训

这里只留会影响后续判断的东西。当前状态见 [STATUS.md](STATUS.md)，实验数字见 [EXPERIMENTS.md](EXPERIMENTS.md)，名词见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md#名词表)。

## 目标与数据底线

- 收集单位是**角色**，不是配音演员。允许出现新角色，不把不认识的角色硬塞给几个已知身份。
- 需要的是声音素材，字幕只提供时间边界。不为此增加语音转文字或文字识别环节。
- 先解决身份分类，语气词和噪声后置。「一条片段里只有一个人说话」是工作假设，不是检测结论。
- **原始素材、对照画面做出来的人工记录、有效模型和昂贵缓存必须保留。** 分析用 16 kHz，导出从原采样率人声轨切；升采样补不回丢掉的高频。删除之前先核对引用。
- 所有片段走同一套处理，全部抽人声，不逐条挑「这条干净就用原音轨」。数据集内部一致比单条片段的绝对音质重要。
- 人工真值只有对照画面确认出来的名字。给算法提供身份的参考片段必须从打分中排除。
- 片段范围不同就不能继承标签。同一个模型产出的标签不能用来验证该模型。

## 会重复犯的错误

**关于取样和统计**

1. **样本小到某个数是 0 的时候，那个 0 说明的是样本，不是系统。** 62 条标签上「错误合并为零」，445 条标签上是 68 对；「该合没合的全是短片段」的依据只有 31 对配对。
2. **同一批标签既调参又打分，看不出问题；换一批标签才看得出。** 分两步的分组做法在旧标签上零错误合并、多连 19 对，全量标签上多出 989 对错误合并。
3. **调参时看到的增益会缩水。** `anime-va` 在前两集上多连 504 对，独立检验只多 9 对。换模型这个决定是对的，但幅度别信调参时的数字。
4. **独立检验的打分口径要在标注之前写死。** 第 3 集标完后 `anime-va` 在两个口径下差别很大（预先约定的口径只多 9 对，事后换的口径多 711 对）。先定口径，才没有挑对自己有利那一种的余地。
5. **配对不是独立观察。** 一个角色有很多条片段就会组合出很多配对，换参考之后打分集也变了，不能把「该合没合的数量下降」直接当改进。
6. **零错误合并不等于成功。** 每条片段各自成组也能做到。必须同时看该合没合、组数和标签覆盖。

**关于调参数**

7. **按整组平均距离合并时，全局距离分界线不是常数。** 池子越大，整组平均距离越难达标，同一分界线合并越保守。在会持续增长的语料上，「调一个分界线」本身就是个会过期的答案。
8. **不同模型的相似度刻度不通用。** `anime-va` 同一角色的相似度中位数 0.337，`redimnet2-b6` 是 0.541。照搬分界线会扫在毫无意义的一段上。
9. **不从结果跳到根因。** 换模型或换参考法没有改善，不足以证明声纹这一环没问题。先诊断，再决定改哪一环，不要轮流试模型和分界线。

**关于标签和数据处理**

10. **机器给的标签不能当真值。** 给机器分出来的组起个多数标签再拿它打分，会把组内混进的错人藏起来。
11. **旧范围的标签不能贴到新范围上。** 曾把旧的大段身份用到新的小段上，夸大了打分覆盖。
12. **各集分别标注时，同一角色在每集必须用同一个名字。** 第 1 集的 `红毛` 和第 2 集的 `Nice Nature` 曾被当成两个人，把一次正确的合并记成了错误合并。新集标注前先对照 `annotations/names.json`。
13. **片段 ID 是集名加起止时间的哈希，跟邻居无关。** 所以往片段表里只增不改能保住已有标签；重切没有这个便宜可占。
14. **中心点会固化上游的错误。** 曾把混进错人的组直接平均成中心点，又把片段级的分界线搬到中心点上，造成大量错误合并。当前的全局分组不用机器身份标签，也不做两层中心点合并。

**关于做过头的过滤**

15. **音质排名不能保证身份或纯净。** 取前 50% 仍会漏过语气词和音效，也会丢掉可用片段。这条路线和相关依赖已移除，小组不能全部吞进一个杂物组。
16. **想按「字幕带定位标记」筛掉招牌和字幕组名之前先数一遍。** 三集里带定位标记的对白行绝大多数是真台词，这个过滤器会丢掉正片内容。
17. **不再用模型判断片段里有没有人说话。** 旧的重叠切法就是这么做的，丢了四成对白行。也不要引入模型去区分角色说话和环境人声。
18. **普通降噪不等于识别并去掉另一个角色的声音。** 卡拉 OK 式分离也不按人物分离，主唱和和声两边都可能有多人，不能当目标说话人提取。

**关于耳朵和眼睛**

19. **凭耳朵记忆分组不是可用真值。** 早期靠耳朵分组有近半标不清，对照画面报名字才有可用身份。旧的现场记录保留，但不把听音组号升级成真值。
20. **试听旧标签只用来帮标注者想起某个名字是谁**，判断仍以画面为准。改成靠耳朵比对相似度，标签就变成人做的分组，而它本来是用来检验机器分组的。
21. **近邻检索正确不等于能靠近邻连成组。** 有标签的片段最近的有标签片段几乎总是同角色，但在全池里最近的多是没有名字的片段：按最近一对合并会经它们把角色链成大团。
22. **诊断「边界异常」要实际试听。** 说话时间线上「不重叠」只保证标注不重叠，音频里另一个人仍然可能在说。第 1 集曾测得 44% 的语音段与前一段换了人且间隔不到 0.25 秒。
23. **字幕一直是可用输入。** 曾误记成没有字幕而绕了路。
