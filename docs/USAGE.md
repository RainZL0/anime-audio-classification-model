# Commands

All the commands are listed only here. For how each step works inside, see [HOW_IT_WORKS.md](HOW_IT_WORKS.md). `uv run avoc --help` lists all the commands, and `uv run avoc <command> --help` lists the options of one command.

| Section | What it does |
| --- | --- |
| [Set up](#set-up) | Before the first run |
| [Processing a new episode](#processing-a-new-episode) | Separate voices, cut clips, compute voiceprints |
| [Labeling and correction interface](#labeling-and-correction-interface) | The daily main workflow: label a few lines, let the machine guess, fix its wrong guesses, export |

The checks to run before sending a change are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Set up

You need FFmpeg on your `PATH`. On Windows, the app's first page has an "Install it for me in one click" button: it runs [install_ffmpeg.ps1](../src/avoc/install_ffmpeg.ps1), which installs [Scoop](https://scoop.sh) if you have none and then FFmpeg with it, all without administrator rights, and avoc can use it at once without a restart. To install it yourself, run `scoop install ffmpeg` if you have Scoop, or download the Windows build from [ffmpeg.org](https://ffmpeg.org/download.html), unzip it, and add its `bin` folder to the `PATH` environment variable. `avoc doctor` says the same when FFmpeg is missing. For the GPU setup and notes on each model, see [TOOLS.md](TOOLS.md).

```powershell
uv sync --locked
uv run avoc doctor
```

`doctor` lists each item in turn: the operating system, the graphics card, FFmpeg, the voice separation model, the Hugging Face token, and the free disk space. Items marked "missing" must be fixed first. Items marked "optional" can be left alone and the tool still works. "Untested" means a system other than Windows: avoc mostly works there, but it is tested on Windows only.

## Processing a new episode

```powershell
uv run avoc add workspace "Episode 08.mkv" --subs "Episode 08.ja.srt" --display-subs "Episode 08.zh.ass" --offset -0.95
```

**Give subtitles in the spoken language as `--subs` when you have them**, and a translation you read as `--display-subs`. Each clip's text is then its own subtitle line, and an entry where two people speak is cut into one clip per person ([how](HOW_IT_WORKS.md#flow)). The secondary subtitles are only shown while labeling; if they do not line up, `add` warns and still finishes, and `set-display-subtitles` below attaches them later. Cutting from a translation also works, but then the episode has no text and can only be exported as sound ([why](DECISIONS.md#settled)); to get text later, delete the episode and add it again.

The interface can also add an episode, with the same steps ([how](#labeling-and-correction-interface)). `add` does everything in one command: it extracts the audio track, separates the voices, cuts clips along the subtitle lines, and then computes the three voiceprints that the interface needs. If the episode name is left out, it uses the next unused `epNN` in the workspace. You can also name it with `--name`. When the main subtitles are not in the spoken language, `add` still finishes but warns that the episode can only be exported as sound. If the run stops halfway (for example, because there is not enough GPU memory), fix the problem and run the same command again. It picks up where it stopped: clips that are already cut and voiceprints that are already computed are not recomputed. If the clip-cutting step itself fails, the half-built folder is deleted.

Both the video and the subtitles are required. The subtitles can be in any common text encoding, and the dialogue [styles](HOW_IT_WORKS.md#glossary) are picked automatically ([how](HOW_IT_WORKS.md#flow)). `add` prints the styles it used and the ones it left out. To check a file first, run `uv run avoc styles "subtitles"`: it lists each style with its line count, time range and sample lines, and marks the ones that would be picked with `*`. If the choice is wrong, give the styles yourself, for example `--styles "Default,Default - Top"`. In the app's add form, the same list appears under the subtitle path once it is filled in, with check boxes. If a warning says some lines still contain marks, see [SUBTITLES.md](SUBTITLES.md#when-it-warns). The audio track is extracted from the video by default. If you have a lossless audio track on the same timeline, give it with `--audio`. If its length differs from the video by more than 0.5 seconds, it is refused. `--spoken ja` (or `zh`, `en`, `ko`) says which language the voices speak. The voices are taken from the audio track tagged with it, and exported text must be in it. When it is left out, a Japanese track is used if the video has one, else the default track; the language comes from the track's tag, and with no tag Japanese is assumed. `add` prints which track it used and lists the others ([how](HOW_IT_WORKS.md#flow)). `--device` defaults to `auto`: it uses the NVIDIA GPU if there is one, and otherwise the CPU. On the CPU, voice separation switches to full precision. The `--device` option of `prepare` and `embed` works the same way.

**Giving `--offset` directly is recommended.** For the same source and the same subtitle group, the offset is stable (measured on episodes 1 to 3: -0.95, -0.96, -0.96). When it is given, speech detection does not run at all. If it is not given, the offset is measured with pyannote. That requires you to accept the terms on the [model page](https://huggingface.co/pyannote/speaker-diarization-community-1) first, create a Read token on the [tokens page](https://huggingface.co/settings/tokens), and then run `uv run hf auth login` and paste it. An account is free. The add form shows these steps when the token is missing. Without a token, `add` and `prepare` report the error right at the start. They do not stop halfway through.

If you prefer to run the steps one at a time, `add` is equal to the following:

```powershell
uv run avoc prepare "video" --subs "subtitles" --name ep08 --out workspace/episodes/ep08 --offset -0.95
uv run avoc embed workspace/episodes/ep08 --model anime-va
uv run avoc embed workspace/episodes/ep08 --model anime-char
uv run avoc embed workspace/episodes/ep08 --model redimnet2-b6
```

## Labeling and correction interface

The workspace is a folder. Its `episodes/` subfolder holds the episodes (the output of `add` or `prepare`), and labels are saved automatically in `labels/`. This repo uses the folder `workspace/`, which git ignores.

```powershell
uv run avoc app workspace
```

Open `http://127.0.0.1:8765` in your browser. `--port` changes the port. `--no-open` stops the browser from opening by itself. `--reload` is for development: it restarts the server when a Python file of avoc changes ([CONTRIBUTING.md](CONTRIBUTING.md#web-app)). `--model` can be repeated, to use only the named voiceprint models. The part of the address after `#` records the current view, episode, character and selected line, so after a refresh you return to the same spot. Episodes whose voiceprints are not all computed (usually because `add` was interrupted) are not loaded. They are listed on the command line at startup, and the other episodes work as usual. The first time a workspace with episodes but no labels is opened, a getting-started guide opens: the four views in the order they are used, each with what it shows and how to work in it, from the first label to the export. Open it again with "Guide" in the top bar, or from the shortcuts dialog (`?`). When the workspace has no episodes at all, the page is the "Add an episode" form, with one line on what the tool does.

Adding an episode from the interface: on that first page, or with "+ Add an episode…" at the bottom of the episode menu. Give the video, the language the characters speak (by default taken from the audio track; the form shows which track and language; change it only to collect a dub), the main subtitles (best in that language), and, if you like, secondary subtitles you read, such as a translation (`--display-subs` on the command line). The form shows the language of each subtitle file. When the voices are for reading text aloud (GPT-SoVITS and such), the main subtitles must be in the spoken language (a bilingual file counts): with a translation there, Start stays off and the form says to put the translation under secondary subtitles, or, before the first episode, to choose "Sound only". With "Sound only" picked, a translation is accepted as the main subtitles, and the form warns in large type that such an episode can never give text later; if unsure, pick reading text aloud. Press "Browse…" next to each box to pick the file in the system's file window, or paste the path ([where the window opens](UI_DESIGN.md#typing)). If the window cannot open (for example a Linux Python built without Tk, or no desktop), the page says so; paste the paths instead. The offset box is filled in with the last episode's offset. Start runs the same `avoc add` as on the command line, in a separate process. The progress lines show as it goes, and library warnings show only if it fails. Separating the voices of one episode took about 12 minutes on an RTX 4060 Laptop GPU; the voiceprints take under a minute. You can close the dialog and keep labeling; a button at the top shows that it is still running, and the new episode appears in the menu when it is done. Stop ends it. If it stops or fails before the clips are cut, the half-built folder is deleted, and carrying on cuts them again from the start; that step is the slowest. After the clips are cut, finished steps are kept. Either way the episode is listed under "Unfinished episodes" with a "Carry on" button, which reruns it with the files it was started with. Those files are noted in `adding.json` in the workspace until the episode is added, so the list is the same after the server restarts, including a restart under `--reload` while an episode was being added; that run stops by itself when its server ends. An episode whose clips were never cut also has a "Give up" button, which deletes its note and any half-built folder. Only one episode is added at a time.

Give names only to the people you want to collect (the target characters). Label everyone else "Other" with the Q key, including anyone you are not sure is a target. Clips where several people speak and none of them is a target are also labeled "Other", and so are clips that are not speech, such as cheers and sound effects. The target character's own laughs and sighs count as the target's voice, so label them as the target. Each target character has two options, chosen in one go. The number key gives the clean target. Shift plus the same number gives "target, low quality". Use the low-quality option for clips with heavy background sound or with several people talking at once. Those clips are not used to recognize the character. They are skipped on export and written to `rejected.tsv`. With two target characters, the bottom bar has 5 options in all: four for the two targets (clean and low quality for each), plus "Other". Next to each target character's guess on the left there is also a "Low quality" button. When you change a clip to the clean target or to "Other", "Low quality" is removed automatically. There can be several target characters. You can add or remove them at any time in the Characters view. For how existing labels are handled when you add or remove a target, see [HOW_IT_WORKS.md](HOW_IT_WORKS.md#labeling-and-correction-interface).

The line between the picture side and the list can be dragged to change their widths. The width is remembered in the browser, and double-clicking the line puts it back.

The tabs at the top come in two boxes. The first box holds the episode menu with Groups and Scenes, which show only that episode. The second box, "All episodes", holds Characters and Export, which cover every episode, so switching the episode does not change them.

- **Groups (G)**: start here when there are no labels yet. The machine puts clips that sound alike into one group, so you can label many lines at once. Tick the lines of one person, or press "Select all"; Shift+click ticks every line between the last ticked one and this one. Then pick who they are from the row of buttons under the group. It is the same as the bottom bar, in the same order and with the same keys: the target characters, "Other", and "New character", which makes them a new target character whose name can be filled in later. The character the machine guesses most often in this group is marked the same way as its top guess on the left. When a group mixes several people, tick and label them in turns. The number keys, Q, N and the bottom bar also label the ticked lines while any are ticked; with none ticked, they label only the line playing. A labeled line stays in the group, shows what it was labeled as, and can no longer be ticked. Undoing with Z restores the group as it was.
- **Scenes (S)**: lists all the lines by episode and scene, in order. The left side shows the picture and the machine's ranking of its guesses. "Vocals only" is on by default: the picture plays, but the sound switches to the separated vocals. To hear the original sound, click "Original sound". Beside it you can choose 1x, 1.25x, 1.5x or 2x speed, and the reference audio plays at the same speed. Both settings are remembered, so they stay after a refresh. Pressing Space, or clicking the selected line again, replays it. When you cannot tell who is speaking, choose "More context" below the line: "None", "±5 s" or "±15 s" plays that much extra time on each side. L steps through the three. The choice stays when you move to another line and after a refresh. If a line cannot play, the picture says why, and "Cut again" throws away the saved clip and cuts it again. Clicking the picture pauses or plays; the icon in its bottom right corner shows which. Each target character has a reference sound. Enter accepts the first guess. The number keys pick a target character from the bottom bar. Q labels "Other". F shows only "Only to do". Lines shorter than 1 second, with no other dialogue within 0.5 seconds on either side, are marked "Too short, skipped". They do not count as work to do, and they are hidden by default in "Whole episode". Click "Show short ones" to list them. Lines shorter than 0.5 seconds with other lines close by are not skipped: they show as "Too little voice", and you pick the character yourself. You can still label them if you want.
- **Characters (O)**: at the top of the left side are the target characters. Below them are characters that are no longer targets but still have labels. The last row is "Other". Each row shows, on the right, how many lines have been confirmed, how many the machine assigned to it, and the total length of the confirmed dialogue. Open a character to see first the lines the machine assigned to it, starting with the least confident. You can play them one after another. When you hear a wrong one, label it as the right person, or press Q for "Other", and it leaves this list. After listening to the rest, press Shift+Enter ("Confirm the other N lines") to confirm the remaining lines. Below that is "Maybe missed": lines the machine did not assign to this character, but that might be it. They start with the most similar, and are labeled like any other line. Here you can also rename characters, merge them, set an avatar, and set or unset a target character. "Other" can also be opened. Each line there shows which target character the machine thinks is closest, and with what probability. Confirmed lines are sorted starting from those closest to a target, so wrong labels show up first.
- **Export (E)**: choose the characters (the target characters start ticked) and the format (one folder per character with sound only, or GPT-SoVITS with each line's text). You can export only the lines that a person has confirmed, or also include the lines the machine is confident about. When it is done, "Open the folder" shows the export in the file manager. For GPT-SoVITS, the text is in each episode's spoken language ([how](HOW_IT_WORKS.md#labeling-and-correction-interface)). The list under "Text of each line" shows, for each episode, the language spoken (change it there if the audio track's tag was wrong; "assumed" means there was no tag), where the text comes from, and how many target lines have no matching text. An episode cut from a translation has no text and can only be exported as sound. Clips without text are not exported; the details are in `rejected.tsv` in the export folder. While labeling, such clips already show "No text to export" with the reason. The output folder starts as `exports/<today's date>` inside the workspace, shown in full, or `<date>-2` and so on once that one holds an export; change it, or pick another with "Browse…". A relative path typed there starts from where `avoc app` was started, as in every path box. What the voices are for is chosen once, at the top of the add form before the first episode ("What the voices are for"; it starts at reading text aloud, which keeps both ways open), and kept in the workspace (`labels/purpose.json`); after that the add form and Export only show it. Switching midway is not supported yet ([roadmap](ROADMAP.md#labeling-interface)). With "Sound only (RVC and such)", the labeling views leave out everything about exported text ("No text to export" and its reasons), the add form accepts a translation as the main subtitles, and Export has only the sound-only format. With reading text aloud, Export can still write sound only, for RVC, without changing the choice. A workspace made with `avoc add` alone has no choice recorded and works as reading text aloud until the add form records one.

Identifying people mainly relies on avatars, and names can be left blank:

- Press N to label the current line as a new character. A dialog asks for its name; you can leave it blank, and it then gets a temporary name such as "Character 1" or "Character 2". "Cancel" (Esc) takes the new character back, and the lines return to how they were. Later, in the Characters view, click "Name" to fill in the real name. In the New character dialog, a name another character already has is refused. In "Name" or "Rename or merge" in the Characters view, typing another character's name merges the two; the dialog says so before you save, and Z undoes it. "Other" is never a name.
- A character with no avatar shows a picture generated from its number. The background color, shape and pattern all change together, so different characters are easy to tell apart at a glance.
- Cropping an avatar: when a new character is created and there is a picture of the line, the same dialog also crops an avatar ("No avatar" keeps only the name). Later, click the avatar to crop it. You can do this from the confirmed lines on the left, or from the avatar at the top of the Characters view. Drag the box to move it. Drag the bottom-right corner or use the scroll wheel to zoom. Use the slider to change the frame, and press Enter to save.

Each label is saved to disk and the model is retrained right away. Backspace (or Delete) clears the label of the current line and returns it to the machine's guess. Confirmed lines also have a "Clear label" button on the left. Z undoes the last step, and you can keep pressing it to go further back. Creating, renaming and merging characters are also undone. Avatars and setting or unsetting a target character are not part of undo. Press `?` to see all the shortcuts. The page uses a light color scheme by default. You can switch to dark mode at the top right. Next to it, the EN / 中文 button switches the page between English and Chinese; the first time, the page follows the browser's language. Messages from the server, such as errors, follow the page language. Both choices are remembered in the browser.

Commands for filling in information for older episodes:

```powershell
uv run avoc set-video workspace/episodes/ep01 "Episode 01.mkv"
uv run avoc set-subtitles workspace/episodes/ep01 "Episode 01.zh.ass"
uv run avoc set-display-subtitles workspace/episodes/ep08 "Episode 08.zh.ass"
uv run avoc set-spoken-language workspace/episodes/ep01 ja
```

- `set-video`: records the video for an episode that was processed before `prepare` required it. If the length does not match the audio track, it is refused.
- `set-subtitles`: adds subtitles to an episode that has none recorded. The offset is worked out from the existing clips, and the dialogue text is found by matching the times that overlap.
- `set-display-subtitles`: attaches subtitles in a language you read to an episode cut from subtitles you don't. They are only shown while labeling. The offset is measured automatically; if it does not line up with the main subtitles, it is refused.
- `set-spoken-language`: corrects the language an episode speaks when the audio track's tag was wrong or missing. The voices already cut stay as they are; to cut from another audio track, add the episode again with `--spoken`.
