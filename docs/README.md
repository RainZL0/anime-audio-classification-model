# 文档索引

## 各文档的职责

每份文档有唯一的职责范围。**同一件事只在一个地方写**，其他地方引用而不复制，否则必然漂移。

| 文档 | 管什么 | 不管什么 | 变动频率 |
| --- | --- | --- | --- |
| [`../README.md`](../README.md) | 项目是什么、怎么装、一句话状态、文档入口 | 任何细节 | 低 |
| [`DESIGN.md`](DESIGN.md) | 管线结构、数据模型、各阶段**要解决什么问题**、失败模式、评估方法 | 具体用哪个模型、进度、决策理由 | 低 |
| [`TOOLING.md`](TOOLING.md) | **选型的唯一事实来源**：具体的库、模型、检查点，以及为什么选它 | 管线结构、进度 | 中 |
| [`ROADMAP.md`](ROADMAP.md) | 里程碑、**当前状态**、下一个动作、阻塞项、开放问题 | 设计、选型 | 高 |
| [`DECISIONS.md`](DECISIONS.md) | 决策记录：做过什么取舍、为什么、代价是什么 | 现状、计划 | 追加式，只增不改 |
| [`PRIOR_ART_AUDIT.md`](PRIOR_ART_AUDIT.md) | 前身项目 `anime-audio-classification-model` 错在哪，作为「不要再犯」的记录 | 本项目的任何内容 | 冻结 |

## 维护约定

- **选型变了**：改 `TOOLING.md`，若影响管线结构再改 `DESIGN.md`，并在 `DECISIONS.md` 追加一条。
- **进度变了**：只改 `ROADMAP.md`。`README.md` 里只有一句话状态，跟着里程碑走。
- **决策变了**：`DECISIONS.md` 里**不修改旧条目**，追加新条目并把旧条目状态标为「已取代 by ADR-NNN」。决策的演变过程本身有价值。
- **发现某段内容出现在两个文档里**：选一个作为归属地，另一处改成链接。

## 阅读顺序

第一次接触这个项目：`../README.md` → `DESIGN.md` → `ROADMAP.md`。
想知道「为什么不那样做」：`DECISIONS.md`。
想动手改代码：`ROADMAP.md` 的「下一个动作」。
