# 流程与数据

## 唯一路线

1. `prepare`：分离人声并保持源采样率；字幕加上每集偏移后，一行对白一个片段。没有显式偏移时用 pyannote 说话时间线辅助对齐，**不采用它的身份标签**。低重合度报错，不悄悄退回另一条流程。
2. `embed`：把至少 1 秒的片段转成单位长度声纹向量。短片段仍留在总表。缓存绑定片段文件、分析音频内容和模型名，输入变化必须重算。
3. `group`：全系列片段直接按声纹分组，不先平均成每集中心点。默认平均连接、余弦距离阈值 0.5 是保守起点，尚待新集验证。连接规则可换成 single、complete 或 mutual_knn（互为 k=3 近邻且在阈值内才连边，再取连通分量），供对照用。小组不会被并进杂项桶。
4. `evaluate`：只用人工身份归档，同音轨、毫秒范围完全匹配才参与评价。报错合、漏合、未匹配标签、未归属片段与各角色组数。
5. `export`：按分组从原采样率人声轨切 WAV；未归属片段另存。保留分组快照与来源表。响度统一但不削顶。

音频质量不是当前闸门。`single_speaker` 是工作假设，不是检测结果。

以上是新准备流程。已有两集保留旧的“字幕与检测语音段交集”边界，以固定输入做对照；不代表已用新切法重跑。具体进度见 [STATUS.md](STATUS.md)。

## 评估怎么读

- **嵌入 / 声纹**：把一段声音变成一组数，用来比较身份。余弦距离越小，向量方向越接近，但它不是身份概率。
- **分组 / 聚类**：根据这些距离把片段归组；平均连接比较的是两组所有片段之间的平均距离。表示、距离和分组规则是不同环节。
- **错合**：不同角色同组。**漏合**：同角色不同组；音频仍在，并没有丢失。
- **同人配对总数**：对每个角色有标签的片段数 n，计算 n(n−1)/2，再按角色求和；不是对全部标签不分角色计算组合数。同人配对找回率是正确连接数除以这个总数。
- **参考 / 支持样本**：提供身份给算法的片段，必须排除评分。对照基线也排除相同片段。已经用于试方法的剩余标签仍不能称为全新盲测。

例如同角色有 A、B、C 三条，A/B 同组、C 单独成组：同人配对共 3 对，正确连接 1 对，漏合 2 对。只报错合为零会隐藏这个问题。

评估只统计时间精确匹配的人工身份。报告另列未匹配标签、特殊标签、已标注但未归属的片段和已排除参考。未归属片段按各自独立组参与配对评分；未标注部分不能当作“无混人”。当前代码的 adjusted_rand 是综合分，不能替代错合与漏合的具体数量。

## 目录

```text
src/avs/
  cli.py                  命令入口
  project.py              一集与片段的数据契约、内容指纹
  pipeline.py             准备、声纹缓存、分组、导出的编排
  audio.py                分离人声、分析副本、字幕对齐所用说话时间线
  embeddings/extract.py   ReDimNet2 / WeSpeaker
  stages/subtitle.py      字幕读取和偏移
  stages/cluster.py       全局声纹分组
  stages/export.py        原采样率导出
  evaluation/identity.py  身份评估
  evaluation/compare.py   同片段、同标签的模型阈值对照
  evaluation/references.py 身份参考实验与参考排除评分
  evaluation/diagnose.py  近邻检索、距离分布、分组对照与错误实例
  labeling.py             全量随机抽样、直接保存人工归档
  label_page.py           姓名标注页面
```

每集 `episode.json` 记录素材与音轨路径，`segments.json` 记录 ID、集名、起止时间。声纹在 `embeddings/<model>/`，矩阵与元信息按行对应。修改片段后旧缓存会报错，不能继续用。

`groups.json` 自带各集音轨位置和每条片段的归属；`speaker=null` 表示未归属。当前路径为绝对路径，搬迁项目时需更新音轨位置；片段 ID 只绑定集名和时间，不因目录移动或重分组而改变。

对照实验不同时改片段边界。引入身份样本时必须区分支持样本与评分样本。

## 模型对照

`compare` 读取缓存，核验片段覆盖一致后按模型与连接规则扫描阈值。报告保留输入哈希、全部成绩，以及错合更少且正确连接更多这一标准下未被其他设置超过的候选。阈值按各模型分别比较，不假定两个模型的距离刻度一致；同批标签选出的结果必须再做独立验证。

## 嵌入诊断

`diagnose` 读取各模型缓存，核验覆盖同一批片段后按片段 ID 对齐，再精确匹配人工标签。候选池是全部标签片段，查询排除自身；只有一条标签的角色不作查询，但留作干扰项。每次查询记录 Top-1/3/5 是否命中同角色、最近同人与最近异人的距离、同集与跨集候选池各自的命中（只在该池存在同角色候选时可评），以及在全部片段里的最近邻；未标注近邻只记为线索。配对距离按同人/异人给出分位数、阈值两侧比例、等错点和 AUC，并按配对中较短片段的时长分层。提供分组文件时，另报漏合配对中距离在阈值内的数量和错合距离。错误实例按固定规则选取：同人最远、异人最近、Top-1 错人且领先最多，每类每条片段只出现一次，从原采样率人声轨导出并附两模型距离。

## 参考实验

`references` 有两种试验规则：连接含同名参考的原组，或逐片段比较最近人工参考。前者遇到组内参考身份冲突就保留原组；后者要求距离足够近并领先另一参考角色至少 0.05，不通过时保留原组，不把预测当新参考扩散。后者可能拆开原本正确的组，这个代价也计入漏合。

参考候选的 `support.clip_ids` 会被评估器自动排除。实验使用相同剩余片段给原分组评分；保存每一次划分和完整成绩，不从中挑最好一次。每角色 2 条、种子 0 的候选预先固定，最近参考法还固定距离 0.5。这些规则与阈值只用于探索，未通过新集验证。
