# 人工身份标签

这些文件来自人对照视频确认角色，不能靠重跑恢复，必须保留。

- `names.json`：角色名词表，27 个名字，只是名字，没有任何片段归属。标注页用它给候选名和数字键排序。
- `ep01-full.json`、`ep02-full.json`：两集全部片段的重标（ep01 242 条、ep02 243 条）。这是当前唯一的验收真值。
- `coverage-ep01.json`：标注者试听 `runs/coverage/ep01/holes/` 后，对每个「整段没片段却有台词」的空洞给出的判断（该收 / 不该收 / 待定）。同样是听过才有的结论，重跑恢复不了。
- `legacy/`：重构前的现场姓名记录、早期听音分组记录及抽样上下文。保留备查，不能把 `labels_groups` 当身份真值。

2026-09-06 删除了 `ep01_v4.json` 与 `ep02.json`（各 35 / 46 条抽样标签）。抽样标注每条都要重新定位画面，力气大半花在找位置而不是认人上，覆盖也不完整；改成两集全量重标。删除前把用过的角色名提取到了 `names.json`。文件内容仍在 git 历史里（`git show b37ef47:annotations/ep01_v4.json`），但 `docs/EXPERIMENTS.md` 里基于那批标签的数字已经无法重算。

`name` 是人名；`__multiple__`、`__unclear__`、`__not_speech__` 是特殊标签；`null` 表示尚未标注。评估只精确匹配同一音轨和时间范围，不把旧片段标签猜着迁移到新边界。

新增标注命令见[根 README](../README.md)。

每次提交直接保存到这里，不再等关闭服务才从被忽略的 runs 目录归档。已有归档会继续使用；边界不同则要求新文件名，不能覆盖旧人工工作。
