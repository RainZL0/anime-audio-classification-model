# 人工身份标签

这些文件来自人对照视频画面确认角色，不能靠重跑恢复，必须保留。

- `names.json`：角色名词表，只是名字，没有任何片段归属。标注页用它给可点的名字排序。
- `ep01-full.json`、`ep02-full.json`、`ep03-full.json`：三集的人工身份，是当前唯一的验收真值。
  第 3 集 375 条全部标完；第 1、2 集各标完原有的 242 和 243 条，后来补进片段表的 324 条还是空的。
- `coverage-ep01.json`：标注者试听第 1 集那些「整段没有片段却有台词」的空档之后，逐处给出的判断
  （该收 / 不该收）。同样是听过才有的结论。
- `legacy/`：重构前的现场姓名记录和早期靠耳朵分组的记录。保留备查，**不能把靠耳朵分出来的组号当身份真值**。

`name` 是角色名；`__multiple__`、`__unclear__`、`__not_speech__` 是特殊标签；`null` 表示还没标。
打分只精确匹配同一音轨、同一毫秒时间范围，不把旧片段的标签猜着挪到新边界上。

把一次正确的合并记成了错误合并。新集标注前先对照 `names.json` 和上一集的归档。

标注命令见[根 README](../README.md)。每次按下就存这里，已有归档会继续使用；片段边界不同则要求
换新文件名，不会覆盖旧的人工工作。
